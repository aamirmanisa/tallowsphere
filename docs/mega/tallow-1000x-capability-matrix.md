## Purpose

This matrix classifies the major capabilities required for the Tallow 1000x-class scraper/browser/data automation upgrade. Every row should stay grounded in concrete file, doc, test, command, or observed runtime evidence.

## Status Legend

| Status | Meaning |
| --- | --- |
| Implemented | Code or scripts exist and appear wired into a user-facing or internal path. |
| Partial | Some implementation exists, but contracts, integration, tests, production behavior, or verification are incomplete. |
| Stubbed | Interface or placeholder exists, but production behavior is not implemented. |
| Documented | Described in docs, but implementation evidence has not been verified. |
| Missing | Needed for the plan, but no implementation or doc owner was found. |
| Unknown | Not yet audited. |

Confidence scale:

- `High`: concrete source/docs/tests or observed behavior found.
- `Medium`: source/docs found, but production wiring or current runtime behavior still needs verification.
- `Low`: mostly roadmap, research, or inherited evidence.
