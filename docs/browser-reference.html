1. Overview & Core Concepts

What is Tallow Browser?

Tallow Browser is a Chrome DevTools Protocol (CDP) automation library that controls real Chrome/Chromium instances for web scraping, testing, and automation. It provides:

  • 100% real browser automation — controls actual Chrome, not a fake implementation
  • JavaScript rendering — executes JavaScript and waits for page stability
  • Full DOM access — query selectors, interact with elements, extract text
  • Privacy-first architecture — @legal annotation required, PII auto-redaction, stealth profiles
  • Enterprise scale — pools, rate limiting, audit trails, jurisdiction compliance

Headless vs Headed Mode

Headless (default): Browser runs without a visible window. Fastest, best for servers. Start with:

let browser = Browser.launch(headless: true)

Headed: Browser window visible on screen. Useful for debugging. Start with:

let browser = Browser.launch(headless: false)

Distinction: fetch() vs Browser

CRITICAL: These are two different code paths:

fetch(url) makes a raw HTTP request and returns HTML as text — NO JavaScript execution.
Browser.launch() + page.goto(url) launches real Chrome, renders JavaScript, waits for stability.

Use fetch() for static HTML or APIs. Use Browser for JavaScript-heavy sites.

@legal Annotation Requirement

All browser-based scraping requires @legal annotation per GDPR Art.6:

@legal(

2. Installation & Setup

CLI Commands for Browser Management

Install Chrome (Download)

tallow browser install

Downloads and verifies Chrome in system cache. Shows path when complete.

List Installed Versions

tallow browser list

Shows all cached Chrome versions and their paths.

Show Chrome Path

tallow browser path

Returns the path to the current Chrome executable for custom scripts.

Remove Installation

tallow browser remove

Uninstalls cached Chrome binaries. Does not affect system Chrome.

Runtime Requirements

  • Chrome or Chromium (auto-downloaded or system-installed)
  • Minimum 100MB free disk space for cache
  • No special permissions required
  • Works on Windows, macOS, Linux

3. Quick Start Example

This minimal example demonstrates the complete lifecycle:

@legal(
    basis: .public_data,
    purpose: "example scraping",
    robots_txt: .respect
)
fn main() {
    // 1. Launch browser
    let browser = Browser.launch() match {
        Ok(b) -> b,
        Err(e) -> { log.fatal("Failed to launch: {e}"); exit(1) }
    }

    // 2. Create a page (tab)
    let page = browser.new_page()?

    // 3. Navigate to a URL
    page.goto("https://example.com")?

    // 4. Extract data
    let title = page.title()?
    let elements = page.query_selector_all(".product")?

    // 5. Process elements
    elements.each { el ->
        let name = el.text()
        log.info("Product: {name}")
    }

    // 6. Clean up
    browser.close()
}

4. Browser Launch & Lifecycle

Browser Struct

The Browser type represents a Chrome process. It is opaque — managed by the runtime via CDP.

fn Browser.launch(headless: bool = true) -> Result
RequiredCDP Runtime
Launch a new Chrome process. Returns Err if Chrome is not installed or cannot start.
  • headless: true — no visible window (default, faster)
  • headless: false — visible window (for debugging)
Example:
let browser = Browser.launch(headless: true)?
fn browser.new_page() -> Result<Page>
RequiredCDP Runtime
Create a new page (tab) in this browser instance. Example:
let page = browser.new_page()?
fn browser.close()
Cleanup
Close the browser and terminate the process. Do this in a defer block to ensure cleanup: 
let browser = Browser.launch()?
defer { browser.close() }
// ... use browser ...

5. Page API — Navigation & DOM Access

The Page type represents a browser tab. It is the primary interface for interacting with web pages.

Navigation Methods

fn page.goto(url: String) -> Result<NavigationResult>
PrimaryAsync
Navigate to a URL and wait for page load (DOMContentLoaded). Returns navigation result with status code. Example:
let result = page.goto("https://example.com")?
log.info("Status: {result.status_code}")
fn page.reload() -> Result<()>
Reload the current page. Waits for DOMContentLoaded.
fn page.go_back() -> Result<()>
Navigate back in browser history.
fn page.go_forward() -> Result<()>
Navigate forward in browser history.

Page Inspection Methods

fn page.title() -> Result<String>
Get the current page title (from <title> tag). 
let title = page.title()?
log.info("Page: {title}")
fn page.url() -> Result<String>
Get the current page URL (after redirects). 
let current_url = page.url()?
fn page.content() -> Result<String>
Get the full HTML content of the page (rendered, with all JavaScript executed). 
let html = page.content()?
fn page.set_content(html: String) -> Result<()>
Replace the page HTML with custom content. Useful for testing with static HTML. 
let html = "
Test
"
page.set_content(html)?

Element Querying Methods

fn page.query_selector(selector: String) -> Result<Element>
Most Common
Find the first element matching a CSS selector. Returns Err if no element matches. 
let title_el = page.query_selector(".product-title")?
let text = title_el.text()?
fn page.query_selector_all(selector: String) -> Result<[]Element>
Most Common
Find all elements matching a CSS selector. Returns empty array if no matches. 
let items = page.query_selector_all(".product")?
log.info("Found {items.len} items")
fn page.wait_for_selector(selector: String) -> Result<Element>
Wait until an element matching the selector appears in the DOM. Returns Err on timeout (30s default). 
// Wait for dynamic content to load
let dynamic_el = page.wait_for_selector(".dynamically-loaded")?

Scrolling Methods

fn page.scroll_by(delta_x: f64, delta_y: f64) -> Result<()>
Scroll the page by pixel amounts. 
page.scroll_by(0.0, 500.0)?  // Scroll down 500px
fn page.scroll_to_bottom() -> Result<()>
Scroll to the absolute bottom of the page. Useful for infinite-scroll sites. 
page.scroll_to_bottom()?

6. Element API — Interaction & Extraction

The Element type represents a DOM element. Elements are bound to the page that created them.

Text & HTML Extraction

fn element.text() -> Result<String>
Most Common
Get the text content (innerText) of an element, with HTML tags stripped. 
let price_text = element.text()?
log.info("Price: {price_text}")
fn element.inner_html() -> Result<String>
Get the inner HTML (including tags) of an element. 
let html = element.inner_html()?
fn element.attribute(name: String) -> String?
Get an attribute value by name. Returns nil if the attribute does not exist. 
let href = element.attribute("href")?
let id = element.attribute("id")
fn element.tag_name() -> Result<String>
Get the tag name (e.g., "DIV", "A", "P") of the element. 
let tag = element.tag_name()?

Element Interaction

fn element.click() -> Result<()>
Most Common
Click the element. Automatically scrolls into view if needed. 
element.click()?
// Waits for click to complete
fn element.type_text(text: String, delay_ms: i32 = 0) -> Result<()>
Type text into an element (e.g., input field). Focuses first, then dispatches key events. 
input_el.type_text("search query", delay_ms: 50)?
// Waits 50ms between keystrokes for human-like behavior
fn element.hover() -> Result<()>
Hover over the element (triggers :hover CSS and mouseover events). 
element.hover()?
fn element.clear() -> Result<()>
Clear the content of an input field. 
input_el.clear()?
input_el.type_text("new value")?
fn element.focus() -> Result<()>
Focus the element (for input fields, textareas, etc.). 
input_el.focus()?
fn element.scroll_into_view() -> Result<()>
Scroll the element into the viewport center. 
element.scroll_into_view()?

Element Inspection

fn element.visible() -> bool
Check if the element is visible in the viewport (synchronous, no Result). 
if element.visible() {
    log.info("Element is visible")
}
fn element.enabled() -> bool
Check if the element is enabled (e.g., not disabled on a button). 
if element.enabled() {
    element.click()?
}
fn element.bounding_box() -> Result<BoundingBox>
Get the element's bounding box (x, y, width, height) in viewport coordinates. 
let bbox = element.bounding_box()?
log.info("Position: ({bbox.x}, {bbox.y})")

Stealth profiles override browser fingerprints to avoid detection. They set consistent values for:

  • User-Agent, platform, vendor
  • WebGL vendor/renderer
  • Canvas fingerprint noise
  • Touch points and hardware concurrency
  • Languages, timezone, locale

14. Pagination & Data Extraction

Auto-Detect Pagination

@legal(basis: .public_data, purpose: "multi-page scraping")
fn scrape_all_pages(url: String) -> Result<[]String> {
    let browser = Browser.launch()?
    let page = browser.new_page()?

    var all_content: []String = []

    loop {
        page.goto(url)?
        all_content.push(page.content()?)

        // Detect next page automatically
        let pagination = detect_pagination(page)?
        match pagination {
            Some(info) -> {
                url = info.next_url  // Found next page
            }
            None -> {
                break  // No more pages
            }
        }
    }

    browser.close()
    Ok(all_content)
}

16. Content Fingerprinting

BLAKE3-Based Content Deduplication

@legal(basis: .public_data, purpose: "duplicate detection")
fn scrape_and_deduplicate() -> Result<()> {
    let dedup = ContentDedup.create()

    let urls = vec![
        "https://example.com/page1",
        "https://example.com/page2",
        "https://example.com/page1"  // duplicate
    ]

    var dedup = dedup
    urls.each { url ->
        let browser = Browser.launch()?
        let page = browser.new_page()?
        page.goto(url)?
        let content = page.content()?

        let check = dedup.check(content)
        if !check.is_duplicate {
            log.info("New content: {url}")
            dedup = dedup.add(content)
        } else {
            log.info("Duplicate of {check.first_seen}")
        }

        browser.close()
    }

    let stats = dedup.stats()
    log.info("Dedup rate: {stats.dedup_rate * 100}%")
    Ok(())
}

Example 1: E-Commerce Price Scraper

@legal(
    basis: .public_data,
    jurisdiction: [.us, .eu],
    purpose: "competitive pricing analysis",
    robots_txt: .respect,
    rate_limit: 2.per_second,
    retain_for: 7.days
)
fn scrape_product_prices(domain: String, category: String) -> Result<[]Price> {
    let browser = Browser.launch(headless: true)?
    defer { browser.close() }

    let page = browser.new_page()?

    // Navigate to category page
    let url = "https://{domain}/category/{category}"
    page.goto(url)?

    // Extract all product containers
    let items = page.query_selector_all(".product-card")?

    var prices: []Price = []

    items.each { item ->
        let name = item.query_selector(".title")?.text()?
        let price_text = item.query_selector(".price")?.text()?
        let url = item.query_selector("a")?.attribute("href")?

        // Parse price (extract digits)
        let price_val = parse_price(price_text)?

        prices.push(Price {
            name: name,
            price: price_val,
            url: url,
            scraped_at: now()
        })
    }

    Ok(prices)
}

struct Price {
    name: String,
    price: f64,
    url: String,
    scraped_at: String
}

Example 2: Login + Multi-Page Scraping

@legal(
    basis: .contract,
    personal_data: false,
    purpose: "account dashboard monitoring",
    retain_for: 30.days
)
fn scrape_dashboard_multi_page(username: String, password: String) -> Result {
    let browser = Browser.launch()?
    defer { browser.close() }

    let page = browser.new_page()?

    // Navigate to login
    page.goto("https://example.com/login")?

    // Fill in credentials
    page.query_selector("input[name=username]")?.type_text(username)?
    page.query_selector("input[name=password]")?.type_text(password)?
    page.query_selector("button[type=submit]")?.click()?

    // Wait for dashboard to load
    page.wait_for_selector(".dashboard")?

    // Save session for next time
    let session = capture_session(page)?
    save_session(session, "dashboard_session")?

    // Extract all pages
    var all_data = ""

    loop {
        // Get current page content
        all_data = all_data + page.content()?

        // Check for next page
        let next = page.query_selector("a.next")
        match next {
            Some(link) -> {
                link.click()?
                page.wait_for_selector(".dashboard")?
            }
            None -> break
        }
    }

    Ok(all_data)
}

Example 6: Batch Scraping with Rate Limiting

@legal(
    basis: .public_data,
    purpose: "parallel product monitoring",
    robots_txt: .respect,
    rate_limit: 2.per_second
)
fn scrape_batch(urls: []String) -> Result<[]String> {
    let browser = Browser.launch()?
    defer { browser.close() }

    let limiter = DomainRateLimiter.create()

    var results: []String = []

    urls.each { url ->
        // Extract domain
        let domain = extract_domain(url)

        // Check rate limit
        let check = limiter.check(domain)?
        if !check.allowed {
            let wait_ms = check.wait_ms
            log.info("Rate limited {domain}, waiting {wait_ms}ms")
            page.wait_for_timeout(wait_ms)?
        }

        // Scrape
        let page = browser.new_page()?
        page.goto(url)?
        let content = page.content()?
        results.push(content)
    }

    Ok(results)
}
