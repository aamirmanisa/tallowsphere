# Tallowsphere completeness audit — 2026-10-21

Scope: `aamirmanisa/tallowsphere` at `39f203b` (working tree clean). 1,741 tracked files across 170
directories; 923 Rust files (655,442 lines), 262 `.tl`, 232 `.md`, 57 `.py`, 21 `.sh`, 21 `.toml`.
Tracked size 38 MB; `.git`, `target/`, `dist/` excluded (build artifacts are not committed).

**Verdict: not fully complete.** One of the twelve workspace crates does not compile, CI cannot see it,
and four `.tl`-facing functions return success without doing what their names say. The root compiler is
green: 9,139 lib tests passed / 0 failed / 33 ignored (557.34 s at this commit).

---

## 1. Blocking

### A-1 · `tallow-reader` does not compile — the reader daemon cannot be built at HEAD

```
$ cargo check -p tallow-reader --locked
error[E0599]: no method named `apply_stealth` found for opaque type `impl Future<Output = Page>`
  --> crates/tallow-reader/src/engine.rs:101:26
error[E0599]: no method named `delete_cookies_by_prefix` ...
  --> crates/tallow-reader/src/engine.rs:143:20
error[E0308]: mismatched types — expected `&Page`, found `&impl Future<Output = Page>`
  --> crates/tallow-reader/src/engine.rs:150:37
error[E0599]: no method named `get_cookies` ...
  --> crates/tallow-reader/src/engine.rs:154:31
error: could not compile `tallow-reader` (bin "tallow-reader") due to 4 previous errors
# rc=101
```

**Mechanism.** `Page::from_cdp` became `pub async fn` in `400c13b` (2026-10-18, "per-session event
capture, opt-in Runtime, guarded stealth scripts"). `crates/tallow-reader/src/engine.rs` was last
touched in the 2026-10-16 squash (`eb6f38c`) and still calls it as a synchronous constructor, so
`page` is a `Future` and four method calls plus one `&Page` argument are made against it.

**Impact.** `cargo build --workspace` fails; the reader daemon has no buildable binary from this tree;
its 7 unit tests cannot compile either (`cargo test -p tallow-reader --no-run` → rc=101). The published
1.1.3 artifact is unaffected — the release flow builds `--bin tallow` only.

**Class.** Broken integration, not a stub. Loud at build time.

### A-2 · CI's "Check" gate never compiles the crates, so A-1 is invisible

`.github/workflows/ci.yml:76` runs:

```yaml
- run: cargo check --locked --all-targets
```

from the workspace root. Without `--workspace`, cargo's default package selection is the root package
only, so this checks `tallow` and nothing under `crates/`. Measured at this commit:

| Command | Result |
|---|---|
| `cargo check --locked --all-targets` (what CI runs) | **rc=0**, 0 errors |
| `cargo check --workspace --all-targets --locked` | **rc=101**, 4 errors (all in `tallow-reader`) |

The same selection applies to the `test-linux` job (`cargo test --locked --lib`), which therefore runs
the root crate's suite and none of the 12 crates' 1,367 unit tests. This is why a crate could rot for
three days without a red gate.

**Fix, one line:** add `--workspace` to the check job and to at least one test job.

## 2. Deflect — success returned without the substance

### B-1 · `generate_affiliate_link` returns the input URL unchanged for its default provider

`src/stdlib/deals.rs:788`. The default provider is `skimlinks`; the match has arms for
`viglink`/`sovrn`, `amazon`, `walmart`, and `homedepot|lowes|target|costco`, then:

```rust
_ => url.to_string(),
```

Probe (1.1.3 binary, interpreter plane, because `tallow.deals.*` has no native lowering):

```
$ tallow run /tmp/probe_deals.tl
{"status": "contract_stub", "live_execution": false, ...}          # browser_scrape
https://example.com/dp/B000TEST                                     # generate_affiliate_link
rc=0
```

A caller that asks for an affiliate link and omits the provider gets back exactly what it passed in,
with exit 0. **Class: Deflect** — the value's shape is plausible, the operation did nothing.

### B-2 · Placeholder credentials embedded in returned URLs

Same file, in the arms that do run:

| Line | Literal | Effect |
|---|---|---|
| 797 | `redirect.viglink.com?key=INSERT_KEY` | a viglink URL that no account can own |
| 815 | `go.skimresources.com?id=XXXXX` | a skimlinks URL with a literal placeholder id |

Both are returned as `Ok(Value::String(...))`. The register's header records that affiliate *tags* in
`src/browser/affiliate.rs` are placeholders requiring `set_tag`; this stdlib path was not covered by
that note and produces the placeholder regardless of configuration.

### B-3 · Two "contract stubs" return `Ok` instead of refusing — contradicting row #68

`src/stdlib/deals.rs:776` (`browser_scrape`) and `:1508` (`llm_classify`) return
`{"status":"contract_stub", ...}` with exit 0. Register row **#68** describes the feature-gated stubs
as ones where "each refuses with a message naming the disabled feature". These two do not refuse: they
return a payload, and a caller that does not inspect `status` proceeds as if the scrape or the
classification happened.

That makes the register an inaccurate map for this file. Either the functions should return a typed
error (matching "honest stub" as defined in the register header: *visible refusal*), or row #68 must
name them as payload-shaped stubs.

## 7. Method and limits

- Every tracked file was scanned programmatically (pattern census + structural parsers), not read line
  by line by a human; the 923-file Rust tree was inspected through its declarations, dispatch tables and
  build results rather than a full read.
- The declared-versus-dispatched diff was run for module coverage (all 85 modules present) and for
  symbols only where a probe could confirm the result. A name screen alone is not evidence; the three
  `deals` findings above were confirmed by running the calls.
- The workspace-wide build is the strongest single signal in this report: it is a real compile of all 12
  crates, and it fails in exactly one of them.
- Not run: the 1,367 crate-level unit tests (blocked for `tallow-reader`, not attempted for the rest),
  the 228 files under `tests/` (the lib suite is the gate this repository advertises and the only one
  measured here), Clippy, and any network-dependent test.

## 8. Disposition

Nothing in this report was changed. The audit is read-only, per its remit.

Recommended order if these are to be fixed:

1. `--workspace` in the CI check job — makes A-2 impossible to repeat.
2. `crates/tallow-reader/src/engine.rs`: `Page::from_cdp(...).await` and re-check the four call sites.
3. `deals.rs`: return `Err` for `contract_stub` paths and for an unconfigured affiliate provider; drop
   the `INSERT_KEY` / `XXXXX` literals or make them a hard error.
4. CHANGELOG entries for 1.1.2 and 1.1.3; correct the versioning-policy paragraph; either fix or drop
   the `docs/codex/` pages.
