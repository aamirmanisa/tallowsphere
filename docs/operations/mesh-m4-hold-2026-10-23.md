## What M4 needs before a line is written

1. **A transport decision.** `src/stdlib/mesh.rs` models a mesh in one process
   and says `simulated: true` on every struct. M4 makes that false for nodes that
   complete a join handshake. The open question is what carries the frames: the
   existing relay (`docs/operations/` relay notes), or a new framed protocol.
   Both have different failure modes; neither is chosen here.
2. **A threat model for the wire.** The control plane accepts `inject` and
   `stop`; over a network those need authentication. The in-process version has
   no such requirement because the caller already owns the process.
3. **A decision on `simulated`.** Flipping it per-node is the honest option; a
   global flag would make a simulated node claim to be real.
