1. What is Tallow?

Tallow is a privacy-first systems programming language designed to eliminate the most dangerous data handling errors at compile time, not runtime. While Rust prevents memory errors, Tallow prevents legal errors.

Every program you write in Tallow is:

Type-safe for privacy

Private and secret types are tracked through your entire program. The compiler rejects illegal data operations before your code compiles.

Legally compliant by default

Network operations require @legal annotations that prove your code respects robots.txt, rate limits, and data retention laws.

Post-quantum secure

ML-KEM-768 cryptography is the default. Your data is secure against future quantum computers today.

Blazing fast

Native binary compilation, zero garbage collection. Sub-millisecond startup and microsecond HTTP are targets, not yet measured (the default HTTP path adds Tor and a 250 ms/host politeness delay).

Tallow compiles to standalone executables. No runtime, no interpreter, no dependencies. Copy your binary anywhere and it just works.

2. Installation

On Windows (PowerShell)

iwr https://github.com/tallow-lang/tallow/releases/download/v0.4.0/tallow-windows-x86_64.zip -OutFile tallow.zip
Expand-Archive tallow.zip -DestinationPath $env:ProgramFiles\Tallow
$env:PATH += ";$env:ProgramFiles\Tallow"

On Linux / macOS (Bash)

curl -L https://github.com/tallow-lang/tallow/releases/download/v0.4.0/tallow-linux-x86_64-musl.tar.gz | tar xz
sudo mv tallow /usr/local/bin/

3. Your First Program

Create a file: hello.tl

fn main() {
    print("Hello, Tallow!")
}

Run it immediately

tallow run hello.tl

Output:

Hello, Tallow!

Or build it to an executable

tallow build hello.tl

This creates hello.exe (Windows) or hello (Linux/macOS). The binary is self-contained and requires no runtime.

Key insight

tallow run = compile and execute immediately. Good for learning.

tallow build = compile to reusable binary. Use for distribution.

4. Variables and Types

Immutable Variables (let)

let name = "Alice"
let age = 30
let score = 98.5

Variables created with let cannot be changed. This is the default.

Mutable Variables (var)

var count = 0
count = count + 1
print(count)

Use var when you need to reassign. Use let everywhere else.

Constants

const MAX_CONNECTIONS = 10000
const VERSION = "0.4.0"

Type Annotations

let port: u16 = 8080              // unsigned 16-bit integer
let timeout: i32 = 30             // signed 32-bit integer
let rate: f64 = 2.5               // 64-bit float
let active: bool = true           // boolean
let greeting: String = "hello"   // heap-allocated string

Collections

// Arrays (variable length)
let numbers = [1, 2, 3]

// Arrays with type annotation
let items: []String = ["a", "b", "c"]

// Maps (dictionaries)
let config = {
    "host": "localhost",
    "port": "8080"
}

5. Functions and Control Flow

Basic Functions

fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let result = add(5, 3)
    print(result)
}

Functions use implicit returns (no return keyword needed for the last expression).

If/Else

let age = 25

if age >= 18 {
    print("adult")
} else if age >= 13 {
    print("teen")
} else {
    print("child")
}

Match (Exhaustive Pattern Matching)

let status = 200

match status {
    200 -> print("ok")
    404 -> print("not found")
    500 -> print("error")
    _   -> print("unknown")
}

Loops

// For loop
for i in 0..10 {
    print(i)
}

// For loop over collection
let items = ["a", "b", "c"]
for item in items {
    print(item)
}

// While loop
var count = 0
while count < 5 {
    count = count + 1
}

String Interpolation

let name = "World"
let count = 42
print("Hello, {name}! Count: {count}")

Output: Hello, World! Count: 42

6. Structs and Enums

Structs (Structured Data)

struct Person {
    name: String,
    age: i32,
    email: String
}

fn main() {
    let alice = Person {
        name: "Alice",
        age: 30,
        email: "alice@example.com"
    }

    print("{alice.name} is {alice.age} years old")
}

Methods on Structs

struct Rectangle {
    width: i32,
    height: i32
}

impl Rectangle {
    fn area(self) -> i32 {
        self.width * self.height
    }
}

fn main() {
    let rect = Rectangle { width: 10, height: 20 }
    print(rect.area())
}

Enums (Multiple Variants)

enum Status {
    Active,
    Inactive,
    Pending(reason: String)
}

fn main() {
    let status = Status.Pending(reason: "awaiting approval")

    match status {
        Status.Active          -> print("running")
        Status.Inactive        -> print("stopped")
        Status.Pending(reason) -> print("pending: {reason}")
    }
}

7. Error Handling

Tallow has no exceptions. Errors are values using the Result<T> type.

Result Type

Result<T> = Ok(T) or Err(String)

The ? Operator (Error Propagation)

fn parse_number(text: String) -> Result<i32> {
    // ? propagates Err upward automatically
    let num = text.parse::()?
    Ok(num * 2)
}

Matching on Results

let result = parse_number("42")

match result {
    Ok(value) -> print("parsed: {value}")
    Err(msg)  -> print("error: {msg}")
}

bail (Early Return with Error)

fn validate_age(age: i32) -> Result<()> {
    if age < 0 { bail "age cannot be negative" }
    if age > 150 { bail "age too high" }
    Ok(())
}

8. Browser Automation Example

Beginner Tallow's built-in Browser API makes web automation simple and legal.

A Complete Web Scraper

@legal(
    basis: .public_data,
    purpose: "extract public content",
    personal_data: false,
    robots_txt: .respect,
    rate_limit: 1.per_second
)
fn scrape_title(url: String) -> Result<String> {
    // Launch headless browser
    let browser = Browser.launch(true)?

    // Create new tab
    let page = browser.new_page()?

    // Navigate to URL
    page.goto(url)?

    // Get page title
    let title = page.title()?

    browser.close()
    Ok(title)
}

fn main() {
    let url = "https://example.com"

    match scrape_title(url) {
        Ok(title) -> print("Page title: {title}")
        Err(e)    -> print("Error: {e}")
    }
}

Required @legal annotation

Any function that makes network requests, touches files, or stores data must have a @legal annotation. The compiler rejects it otherwise. This proves your code is legally compliant.

9. Privacy Types and @legal Annotations

What are Private and Secret Types?

Tallow enforces privacy through the type system. Some data is more sensitive than others:

private types

Personal data subject to GDPR/CCPA: Email, Name, Phone, Location. Cannot be logged raw, sent unencrypted, or stored without a retention limit.

secret types

Credentials: Password, APIKey, Token, PrivateKey. All privacy rules PLUS never serializable, zero-wiped from memory on scope exit.

Built-in Private Types

type Email = private String
type Phone = private String
type Location = private (f64, f64)
type Name = private String

Built-in Secret Types

type Password = secret String
type APIKey = secret String
type Token = secret String

Safe Ways to Use Private Types

let email = "alice@example.com" as Email

// ❌ COMPILER ERROR: Cannot log email directly
print(email)

// ✅ CORRECT: Log a redacted version
print(email.redact())   // outputs: a***@***.com
print(email.hash())     // outputs: sha256 hex digest
print(email.mask())     // outputs: ****@example.com

The @legal Annotation System

Every network or data storage operation requires a @legal annotation proving you have a legal basis:

@legal(
    basis: .public_data,           // GDPR Art.6(1)(f) — legal basis
    purpose: "competitive research", // what you're using it for
    personal_data: false,           // no PII collected
    jurisdiction: [.us, .eu],      // where users are
    retain_for: 30.days,            // don't keep it forever
    robots_txt: .respect,            // honor robots.txt
    rate_limit: 2.per_second         // don't hammer servers
)
fn fetch_prices(urls: []String) -> Result<[]Price> {
    // Implementation here
}

Legal Basis Values

Basis Use Case
.public_data Publicly available data (e.g., price lists, published articles)
.consent User explicitly agreed (need consent_ref)
.legitimate_interest Your business interest outweighs user privacy (need lia_completed: true)
.research Academic, journalistic, or public interest research
.contract Necessary to fulfill a contract with the user
.vital_interests Emergency situations (rare)

Automatic compliance audits

When you compile, Tallow generates audit logs for every @legal-annotated function. These are court-ready proofs of compliance.

10. Encryption and Cryptography

Post-Quantum Encryption (Default)

let data = "sensitive information"

// Encrypt with ML-KEM-768 (post-quantum standard)
let keypair = KeyPair.generate()
let sealed = data.encrypt(key: keypair.public)

// Decrypt
let plain = sealed.decrypt(key: keypair.private)?
print(plain)

Hashing (Data Integrity)

// BLAKE3 — fastest hash function, default for data integrity
let file_hash = read_file("myfile.dat")?
    .hash()

print(file_hash)  // 64-character hex string

Password Hashing (Argon2id)

let password = "user-password" as Password

// Hash with Argon2id (memory-hard, secure)
let hash = password.hash()

// Verify during login
let user_provided = "entered-password" as Password
let matches = user_provided.verify(hash)
if matches {
    print("login successful")
}

Available Algorithms

Purpose Default Alternatives
Key Exchange ML-KEM-768 X25519 (classical)
Signing ML-DSA Ed25519 (classical)
Data Integrity BLAKE3 SHA3, SHA256
Password Hashing Argon2id Bcrypt, Scrypt
Encryption ML-KEM (PQC) AES-256-GCM, ChaCha20-Poly1305

All cryptographic keys are automatically zero-wiped from memory when they go out of scope.

11. Building and Running

Development Workflow

1 Write your code in a .tl file
2 Test immediately with tallow run
3 Check for errors with tallow check (type-check only, no compilation)
4 Format code with tallow fmt (opinionated style)
5 Build for release with tallow build --release

Build Targets

// Linux 64-bit (default)
tallow build --target x86_64-linux

// Windows 64-bit
tallow build --target x86_64-windows

// macOS ARM64 (Apple Silicon)
tallow build --target aarch64-macos

// WebAssembly
tallow build --target wasm

// Release build (optimized, stripped)
tallow build --release

Project Structure

my-project/
├── tallow.toml              // Project manifest
├── src/
│   └── main.tl            // Entry point
├── examples/
│   └── demo.tl
├── tests/
│   └── main_test.tl
└── tallow.lock              // Locked dependencies
