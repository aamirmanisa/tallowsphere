Introduction to Tallow

Tallow (pronounced /nɪks/ — rhymes with "fix") is a privacy-first systems programming language that enforces legal compliance and cryptographic security at compile time, not runtime.

The One-Sentence Pitch

Tallow is a systems programming language where privacy, legal compliance, and post-quantum cryptography are enforced at compile time — not bolted on after.

Etymology

  • Tallow (German): a water nymph that appears, then vanishes — perfect privacy metaphor
  • To nix: to cancel, erase, void — zero data retention
  • The river Styx: what crosses over doesn't come back

Core Philosophy

Every existing language treats privacy as a library problem. Developers import `crypto`, add GDPR compliance as a post-launch checklist, and implement IP rotation via fragile third-party proxies.

Tallow makes this wrong by default impossible.

Why Tallow Exists

The Problem

  • GDPR fines in 2025: €2.3 billion (+38% YoY)
  • Privacy-enhancing tech market: $3-4.4B (2024) → $28B (2030)
  • NIST PQC deadline: RSA/ECC deprecated by 2030, disallowed by 2035
  • Web scraping compliance: described as "minefield" — every data point has legal strings

Core Features — Five Pillars

Pillar 1: Extreme Performance

  • Target — not yet verified: microsecond HTTP requests, <1ms script startup (unmeasured; the default HTTP path is a synchronous client with Tor egress and a 250 ms/host politeness delay)
  • io_uring backend (Linux 5.1+) for async I/O — partial: optional feature, off by default; single-op file I/O only (no network path)
  • DPDK option for kernel bypass (10M+ connections) — target-only: stub backend only (StubDpdkBackend); no userspace TCP stack exists
  • SIMD string processing — target-only (no SIMD tokenizer in tree); Arena allocators — target-only (not implemented); zero GC — true (no tracing collector)
  • Constant folding in codegen (no comptime language feature)
Operation Python + uv Tallow Target Method
Script startup 80ms <1ms Target — unmeasured; compiled binary only (tallow run may build or run interpreted)
HTTP fetch (1 req) ~2ms ~50µs Target — not achievable as designed (synchronous client; Tor default egress + 250 ms/host delay; no connection pooling)
Parse 10K HTML pages ~8s ~40ms Target — no SIMD tokenizer in tree; scraper/html5ever DOM path
Encrypt 1GB ~12s ~200ms AES hardware acceleration (AES-NI on x86; ARMv8 crypto extensions on ARM)
100K concurrent reqs ❌ Target-only Not implemented — io_uring off by default; no userspace TCP stack

Pillar 2: Privacy by Default

  • private and secret type qualifiers — compiler-tracked
  • Private types: cannot be logged raw, sent unencrypted, or stored without retention
  • Secret types: all of private PLUS zero-wiped from memory on scope exit
  • .redact(), .hash(), .mask() methods on private types

Pillar 3: Legal Compliance in Compiler

  • @legal annotation required on all network-touching functions
  • Compiler-generated audit logs — partial: auto-emission today is plain [AUDIT] fn=… basis=… purpose=… text lines from the self-hosted compiler; native codegen only declares the FFI; structured JSONL is opt-in (tallow.legal.log_audit)
  • Legal basis maps directly to GDPR Article 6
  • Jurisdiction-aware: auto-detects and applies relevant law
  • tallow audit generates source-level compliance evidence (engineering-process evidence, not court evidence by itself; not a certification)

Pillar 4: Post-Quantum Cryptography Default

  • ML-KEM-768 for key exchange (NIST PQC standard) — the .tl/stdlib and vault default; the tallow-crypto Rust crate ships ML-KEM-1024 (parameter-set divergence tracked as an open item)
  • ML-DSA for signatures — ML-DSA-65 on the .tl/stdlib surface; the crate ships ML-DSA-87
  • Argon2id for password hashing
  • All classical algorithms available but not default
  • Hybrid mode (classical + PQC) available for transition period

Pillar 5: Unlimited IP Connections

  • IPPool is a first-class language primitive
  • Scales from 10K (epoll) → 1M (io_uring, feature-gated) — 10M+ (DPDK) is target-only (stub backend)
  • Distributed mode: multiple nodes appear as single pool
  • Auto-tunes kernel parameters at runtime (restored on exit)
  • Per-request IP rotation built in

Privacy Type Qualifiers

Core Concept

Tallow uses the type system to track privacy-sensitive data. The compiler rejects dangerous operations at compile time, not after deployment.

Built-in Private Types

private types represent GDPR personal data. They cannot be:

  • Logged raw (must use .redact() or .hash())
  • Sent unencrypted
  • Stored without a retention limit
type Email = private String
type Phone = private String
type Name = private String
type Location = private (f64, f64)

Built-in Secret Types

secret types represent credentials and keys. All privacy rules PLUS:

  • Zero-wiped from memory on scope exit
  • Never appears in error messages
  • Cannot be serialized to disk or network
type Password = secret String
type APIKey = secret String
type Token = secret String
type PrivateKey = secret Bytes

Working with Private Types

let email = "alice@example.com" as Email

// ❌ COMPILER ERROR: Cannot log email directly
print(email)

// ✅ CORRECT: Use a safe method
print(email.redact())   // "a***@***.com"
print(email.hash())     // SHA256 hex digest
print(email.mask())     // "****@example.com"

Defining Custom Private Types

type SSN = private String
type CreditCard = private String

// Now SSN and CreditCard get all privacy protections automatically

Error Handling

Result Type

fn divide(a: f64, b: f64) -> Result<f64> {
    if b == 0.0 { return Err("division by zero") }
    Ok(a / b)
}

The ? Operator (Error Propagation)

fn process(path: String) -> Result<Data> {
    let raw   = read_file(path)?   // ? propagates error upward
    let parsed = parse(raw)?
    let valid  = validate(parsed)?
    Ok(valid)
}

bail (Early Return)

fn validate(data: Bytes) -> Result<String> {
    if data.len == 0 { bail "empty input" }
    if data.len > 1_000_000 { bail "too large" }
    Ok(data.decode())
}

Matching on Results

let result = divide(10.0, 2.0)

match result {
    Ok(v)    -> print("result: {v}")
    Err(msg) -> print("error: {msg}")
}

unwrap_or (Provide Default)

let value = compute(x, y).unwrap_or(0.0)
let value = compute(x, y).unwrap_or_else { err -> log(err); 0.0 }

Collecting Results

let results: []Result<Data> = urls.map { url -> fetch(url) }
let ok_only = results.filter_ok()             // drop errors
let all_ok  = results.collect_ok()?          // fail if any error
let (ok, err) = results.partition_result() // split into two lists

The @legal Annotation System

Core Rule

Any function that makes network requests, stores data, or returns private types must have a @legal annotation. The compiler rejects it otherwise.

Full Annotation Syntax

@legal(
    // REQUIRED
    basis: .public_data,              // legal basis (see below)
    purpose: "competitive research",   // what you're doing

    // CONDITIONAL (required if personal_data: true)
    personal_data: false,

    // OPTIONAL
    jurisdiction:   [.us, .eu, .uk],
    retain_for:     30.days,
    robots_txt:     .respect,
    rate_limit:     2.per_second,
    lia_completed:  true,
    consent_ref:    "consent-v2",
    dpa_ref:        "dpa-2024-03"
)

Legal Basis Values (GDPR Article 6)

Basis Use Case Notes
.public_data Publicly available data Price lists, published articles, public APIs
.consent User explicitly agreed Requires consent_ref
.legitimate_interest Your business interest outweighs user privacy Requires lia_completed: true
.research Academic, journalistic, or public interest research Applies to news organizations
.contract Necessary to fulfill a contract Only with explicit contractual relationship
.vital_interests Emergency situations Rarely applicable
.legal_obligation Required by law Law enforcement, court orders

Jurisdiction Values

Jurisdiction Law
.us CCPA, CFAA
.eu GDPR
.uk UK GDPR
.ca PIPEDA
.au Privacy Act 1988
.br LGPD
.jp APPI
.sg PDPA
.cn PIPL (strict restrictions)
.global Most restrictive of all applicable laws

Note: compile-time passes exist for GDPR/CRA/NIS2/DORA/AI Act (per-pass maturity varies). CCPA, PIPEDA, LGPD, APPI and PIPL are target-only — jurisdiction values with no compiler enforcement (verified 2026-09-12).

Cryptography Primitives

Design Philosophy

Crypto is a method on the type, not an imported library function.

// NOT this (library approach):
import tallow.crypto
let sealed = crypto.encrypt(secret, algo: .aes_256)

// THIS (Tallow approach):
let sealed = secret.encrypt()        // method on String

Encryption

let data = "sensitive information"

// Default: ML-KEM-768 (NIST PQC standard)
let sealed = data.encrypt()

// Explicit algorithm
let sealed = data.encrypt(algo: .ml_kem_768)
let sealed = data.encrypt(algo: .aes_256_gcm)
let sealed = data.encrypt(algo: .chacha20_poly)
let sealed = data.encrypt(algo: .hybrid)  // X25519 + ML-KEM

// With key
let sealed = data.encrypt(key: keypair.public)

// Decrypt
let plain = sealed.decrypt(key: keypair.private)?

Hashing

// Password hashing — Argon2id (memory-hard, secure)
let password = "user-password" as Password
let hash = password.hash()

// Verify (constant-time)
let ok = password.verify(stored_hash)

// Data integrity hashing — BLAKE3 default
let digest = data.hash()
let digest = data.hash(algo: .blake3)
let digest = data.hash(algo: .sha3_256)
let digest = data.hash(algo: .sha2_256)

Key Generation

// Asymmetric keypair
let keypair = KeyPair.generate()         // ML-KEM-768 default
let keypair = KeyPair.generate(algo: .ml_kem_768)
let keypair = KeyPair.generate(algo: .ed25519)
let keypair = KeyPair.generate(algo: .x25519)

// Symmetric key
let key = SymKey.generate()              // 256-bit default
let key = SymKey.generate(bits: 256)

// From seed (deterministic)
let keypair = KeyPair.from_seed(seed_bytes)

// Key serialization
let pem = keypair.public.to_pem()
let der = keypair.private.to_der()
let kp2 = KeyPair.from_pem(pem_string)?

Signing

let keypair = KeyPair.generate(algo: .ml_dsa)  // PQC signing

let signature = keypair.sign(data)
let valid     = keypair.verify(data, signature)

TLS / Secure Connections

// Default: TLS 1.3 with PQC hybrid
let conn = TLSConn.connect("example.com:443")

// Explicit config
let conn = TLSConn.connect("example.com:443",
    min_version: .tls13,
    key_exchange: .hybrid,      // X25519 + ML-KEM default
    verify_cert:  true
)

// mTLS
let conn = TLSConn.connect("example.com:443",
    client_cert: my_cert,
    client_key:  my_key
)

Random

let bytes  = Random.bytes(32)         // cryptographically secure
let int    = Random.u64()
let token  = Random.token(length: 32) // URL-safe base64
let uuid   = Random.uuid()            // UUIDv4

IPPool & Concurrent Requests

IPPool Configuration

// Auto-scaling pool
let pool = IPPool {
    size:     .auto,            // runtime determines
    rotation: .per_request,     // new IP every request
    protocol: .socks5           // .socks5 | .http | .https
}

// Fixed size
let pool = IPPool {
    size:     10_000,
    rotation: .per_request
}

// High-performance (kernel bypass)
let pool = IPPool {
    size:    100_000,
    backend: .dpdk,             // DPDK kernel bypass — Linux only
    rotation: .per_request
}

// With proxy list
let pool = IPPool.from_file("proxies.txt")
let pool = IPPool.from_list(proxy_urls)

// Distributed (multiple nodes)
let pool = IPPool.distributed(
    nodes:             ["10.0.0.1", "10.0.0.2"],
    total_connections: .unlimited,
    coordination:      .gossip
)

Concurrent Requests (pool.map)

// Map over URLs — all run concurrently
let results = pool.map(urls) { url ->
    fetch(url, timeout: 5.seconds)
}

// With error handling
let results = pool.map(urls) { url ->
    fetch(url)?
}

// Filter and transform
let prices = pool.map(urls) { url ->
    let resp = fetch(url)?
    parse_price(resp.body)?
}
.filter_ok()
.flatten

// Controlled concurrency
let results = pool.map(urls,
    concurrency: 100,
    delay:       100.ms
) { url -> fetch(url) }

// Rate-limited
let results = pool.map_ratelimited(urls,
    rate: 10.per_second
) { url -> fetch(url) }

Agent Task System

What is @agent_task?

@agent_task declares a function as an autonomous unit with compiler-enforced permission boundaries. Agents cannot exceed their declared permissions — not at runtime, at compile time.

Full Syntax

@agent_task(
    id:           task_id,
    timeout:      60.seconds,
    max_requests: 1000,
    can_write:    false,        // cannot write to filesystem
    can_store:    false,        // cannot write to database
    can_spawn:    false,        // cannot spawn child agents
    memory_limit: 512.mb
)
@legal(basis: .public_data, purpose: "market research")
async fn research_prices(query: String) -> EncryptedResult {
    let urls  = discover_urls(query)
    let pages = pool.map(urls) { url -> fetch(url) }
    let data  = extract_prices(pages)
    data.encrypt()
}

Available Permissions

Permission Type Default Meaning
can_write bool false filesystem write access
can_read bool true filesystem read access (own workspace)
can_store bool false database write access
can_query bool true database read access
can_spawn bool false spawn child agents
can_network bool true make network requests
can_execute bool false execute shell commands (dangerous)
memory_limit Bytes none max memory consumption
timeout Duration none hard timeout — agent is killed after
max_requests u32 none max outbound HTTP requests

Calling Agents

// Async call
let result = research_prices("gpu prices 2026").await

// With timeout override

// Fire and forget

// Collect multiple
let results = [
    research_prices("topic-a"),
    research_prices("topic-b"),
    research_prices("topic-c")
].await_all()

Compiler Architecture

Compilation Pipeline

Source (.tl)
    ↓
Lexer → Token stream
    ↓
Parser → AST
    ↓
Type checker
  ├── Privacy type flow analysis
  ├── @legal annotation validation
  ├── @agent_task permission verification
  └── Secret type scope tracking
    ↓
Policy/safety passes (@legal validation, privacy flow, agent boundaries)
    ↓
IR generation
    ↓
LLVM optimization passes
    ↓
Native binary / WASM

The @legal Compiler Pass

  1. Collect all functions touching network/storage
  2. For each: verify @legal annotation present
  3. Validate legal basis is appropriate for return types
  4. Validate retention periods (no .forever for personal data)
  5. Generate audit log schema for each annotated function
  6. Emit audit log calls into IR (runs at runtime, zero overhead)

The Privacy Type Pass

  1. Walk entire AST tracking private and secret type values
  2. At each usage site, verify:
    • Not passed to print/log without .redact() or .hash()
    • Not serialized without explicit consent
    • Not returned from functions with wrong @legal basis
  3. For secret types additionally:
    • Insert zero-wipe at end of every scope containing secret value
    • Block all serialization paths at IR level
    • Verify never appears in string interpolation without explicit method

Glossary

Term Definition
@legal Compile-time annotation declaring legal basis for data operations. Required for all network and storage functions.
@agent_task Declares an autonomous function with compiler-enforced permission boundaries.
private Type qualifier for GDPR personal data. Compiler-tracked, cannot be logged raw or sent unencrypted.
secret Type qualifier for credentials and keys. All privacy rules PLUS zero-wiped from memory, never serialized.
IPPool First-class language primitive for managing concurrent IP connections. Scales from 10K (epoll); 1M via feature-gated io_uring; 10M+ (DPDK) is target-only.
bail Early return with error from a Result function.
? operator Propagate Result error up the call stack. Used in functions returning Result.
.redact() Method on private types that returns a safe-to-log version (e.g., "a***@***.com").
PQC Post-quantum cryptography. Defaults are per-layer: ML-KEM-768 / ML-DSA-65 on the .tl/stdlib (+ vault) surfaces; the Rust tallow-crypto crate ships ML-KEM-1024 / ML-DSA-87 (divergence tracked as an open item).
tallow audit CLI command generating legal compliance report for all @legal-annotated functions.
comptime Term used in older docs; not a Tallow language feature. Compile-time work is limited to constant folding in codegen.
io_uring Linux kernel interface for async I/O. Optional feature (off by default), file I/O only, single-op submissions today.
DPDK Data Plane Development Kit — target-only: a stub backend exists; no kernel-bypass networking is implemented.

Example 1: Compliant Price Scraper

@legal(
    basis:        .public_data,
    jurisdiction: [.us, .eu],
    personal_data: false,
    purpose:      "competitive price monitoring",
    retain_for:   7.days,
    robots_txt:   .respect,
    rate_limit:   2.per_second
)
fn scrape_competitors(domains: []String) -> Result<[]Price> {
    let pool = IPPool {
        size:     10_000,
        rotation: .per_request
    }

    let urls = domains.map { d -> "https://{d}/products" }

    let pages = pool.map(urls,
        concurrency: 50,
        delay: 500.ms
    ) { url ->
        fetch(url, timeout: 5.seconds)?
    }?

    let prices = pages
        .filter  { p -> p.status == 200 }
        .map     { p -> parse_prices(p.body)? }
        .flatten

    Ok(prices)
}

fn main() {
    let domains = [
        "competitor-a.com",
        "competitor-b.com",
        "competitor-c.com"
    ]

    match scrape_competitors(domains) {
        Ok(p) -> {
            p.each { price ->
                log.info("price: {price}")
            }
        }
        Err(e) -> {
            log.error("scrape failed: {e}")
            exit(1)
        }
    }
}

Example 2: Privacy-Safe User Processing

struct User {
    id:    u64,
    email: Email,       // private type — GDPR personal data
    name:  Name,        // private type
    token: Token,       // secret type — never logs, never serializes
}

@legal(
    basis:        .contract,
    personal_data: true,
    jurisdiction: [.eu],
    purpose:      "user account management",
    retain_for:   365.days
)
fn create_user(email: Email, name: Name, password: Password) -> Result<User> {
    let hashed = password.hash()     // Argon2id

    let user = User {
        id:    db.next_id(),
        email: email,
        name:  name,
        token: Random.token(length: 32) as Token
    }

    db.users.insert(user)?
    Ok(user)
}

fn log_activity(user: User, action: String) {
    // Compiler enforces: email and name cannot be logged raw
    log.info("user {user.id} performed {action}")
}

fn send_welcome(user: User) -> Result<()> {
    let link = "https://app.example.com/verify?id={user.id}"

    tallow.email.send(
        to:      user.email,
        subject: "Welcome {user.name}",
        body:    "Click to verify: {link}"
    )
}

Example 3: Autonomous Research Agent

@agent_task(
    id:           "research",
    timeout:      2.minutes,
    max_requests: 500,
    can_write:    false,
    can_store:    false,
    memory_limit: 256.mb
)
@legal(
    basis:        .research,
    personal_data: false,
    purpose:      "public market intelligence",
    retain_for:   90.days
)
async fn research_market(sector: String) -> Result<EncryptedReport> {
    let pool = IPPool { size: 1000, rotation: .per_request }

    // Discover sources
    let query_urls = build_queries(sector)
    let sources = pool.map(query_urls) { url ->
        fetch(url, timeout: 5.seconds)?
    }?

    // Extract data
    let articles = sources
        .filter { r -> r.status == 200 }
        .map    { r -> extract_articles(r.body)? }
        .flatten

    // Encrypt and return
    let report = Report {
        sector:   sector,
        articles: articles,
        count:    articles.len,
        generated: now()
    }

    Ok(report.to_json().encrypt())
}

fn main() {
    let sectors = ["semiconductors", "AI infrastructure"]

    let reports = sectors.parallel_map { sector ->
        research_market(sector).await
    }

    reports.each_ok { encrypted ->
        let report = encrypted.decrypt(key: config.master_key)?
        save_report(report)
    }
}
